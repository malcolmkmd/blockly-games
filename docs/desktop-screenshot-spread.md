# Thinka Blockly Games — desktop screenshot spread

Captured from current `master` (`938e6fb`, includes Keys) at a **1280 CSS-pixel** desktop viewport (2×, so 2560px-wide PNGs). No mobile / device-mode.

Built and served locally:

```bash
make deps
make games
python3 serve.py --port 8088
```

Help dialogs and Maze topic explainers were dismissed so each shot is the play surface. About / more-info / empty help-only modals were not captured.
